Scope of this licence
=====================

This CC BY 4.0 licence covers:

  * The annotations (character-offset spans and IOB conversions of
    "Dataset" mentions).
  * The chunking, split assignments, and metadata in data/*.jsonl and
    data/ood_test_labelstudio.json.
  * The documentation files: README.md, SCHEMA.md, this LICENSE.txt.

This CC BY 4.0 licence does NOT cover:

  * The text of the source articles themselves, which remain under each
    publisher's original licence (arXiv, PubMed Central OA subset, and
    other biomedical publishers whose terms permit text-and-data mining).
    Each annotation references its source by persistent identifier
    (arXiv-id, PMC-id, or DOI) so users can retrieve the full article
    from its legitimate publisher.
  * Accompanying source code (training scripts, evaluation scripts,
    notebooks) shipped in the companion repository -- those are released
    under the MIT licence; see LICENSE-CODE.txt.

How to attribute
================

If you use MedSETNER in research, please cite the accompanying paper
(see README.md, section "How to cite"). A machine-readable CITATION.cff
file will be added on de-anonymisation.

A minimal attribution string is:

  "MedSETNER (CC BY 4.0), v1.0.0, [authors withheld for review], 2026."
